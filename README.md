# 우리학교 교육활동 아카이브 v4.3

## 이번 수정
- 관리자 로그인 JWT를 브라우저 localStorage에 저장해 유효기간(8시간) 동안 관리자 버튼을 다시 눌러도 비밀번호를 반복 입력하지 않습니다.
- 새 교육활동을 등록하면 바로 해당 활동의 연도별 운영 정보(연도, 예산, 실제 운영 학년) 입력 창을 엽니다.
- 관리자 교육활동 목록에 삭제 버튼을 추가했습니다. 삭제는 기존 기록 보존을 위해 비활성화(메인 화면에서 숨김) 방식입니다.
- 학년부장 운영기록 상세 화면에서 수정/삭제할 수 있습니다.
- 관리자 목록에서는 삭제 처리된 교육활동을 숨깁니다.

## 기존 교육활동이 2026년에 보이지 않는 경우
메인 화면은 교육활동 기본정보만 있는 항목을 연도별 목록에 표시하지 않습니다. 관리자 메뉴에서 해당 활동의 **연도·예산 관리**를 열어 `2026`년, 예산, 실제 운영 학년을 저장해야 2026년 목록에 표시됩니다. 기존 활동을 삭제/재등록할 필요는 없습니다.

## 배포
1. ZIP의 `client/`와 `server/` 내용을 기존 GitHub 저장소의 같은 경로에 업로드해 덮어씁니다. `README.md`도 업데이트할 수 있습니다.
2. GitHub 커밋 후 Render와 Netlify 자동 배포가 완료되는지 확인합니다.
3. Neon SQL을 다시 실행할 필요는 없습니다. DB 구조 변경은 없습니다.

## 주의: 운영기록 수정/삭제 권한
학년부장 입력을 로그인 없이 사용할 수 있도록 운영기록 수정/삭제 API도 별도 로그인 없이 열려 있습니다. 따라서 사이트에 접근 가능한 사람이면 다른 학년의 기록도 수정/삭제할 수 있습니다. 학교 내부에서만 사용하고, 수정/삭제를 학년부장 본인으로 제한해야 한다면 다음 단계에서 학교 접근코드 또는 기록별 수정 PIN을 추가하는 것을 권장합니다.
